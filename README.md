# Zomato Restaurant Expansion Analysis 📊

**Spreadsheet project | Newton School Data Science Program (Module 1)**

## Problem
Acting as a consultant data analyst for Zomato, I analysed restaurant data to recommend where to open new restaurants.

## Dataset
9,551 restaurants (9,542 after cleaning), 20 attributes, 15 countries.

## Key Recommendations
- **Countries:** Indonesia, Philippines, Turkey (backups: Qatar, New Zealand)
- **Cities:** Tangerang, Jakarta, Pasig City, Makati City, Istanbul
- **Cuisines:** Japanese, Filipino and Indonesian for quality; Cafe and Kebab for volume
- **Pricing:** Mid-range; higher prices showed no link to better ratings
- **Services:** Launch with table booking; trial delivery later

## Skills Used
Data cleaning, XLOOKUP, pivot tables, array formulas, COUNTIFS/AVERAGEIFS, conditional formatting, string functions, charts, interactive dashboard with slicers

## Files
- `Zomato_Project_Presentation.pdf`: summary presentation
- `Zomato_Restaurant_Analysis.xlsx`: full workbook with all formulas and the dashboard
